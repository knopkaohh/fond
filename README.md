# Подари солнечный свет

Редизайн сайта благотворительного фонда помощи детям, рождённым на раннем сроке. Структура страниц и тексты взяты с официального сайта sunlightfond.ru. Визуальная система обновлена: фиолетовый `#5B3A68`, солнечный жёлтый `#F6C94C`, тёплый белый `#FFFDF8`.

Это дизайнерская версия, а не замена официального сайта. Пожертвования в форме не списываются. Реальные переводы — по реквизитам фонда и через СМС «СВЕТ сумма» на номер 3434.

## Что внутри

- Все разделы оригинального меню: о фонде, благотворителям, волонтёрам, школа для родителей, контакты.
- Дополнительно перенесены страницы «Экосистема „Вместе в жизнь“», «Мастерская развития и роста», «Вместе с Курском» и форма пожертвования.
- В шапке и подвале — полное меню, телефоны, почта, адреса, реквизиты и ссылки на соцсети. Все пункты кликабельны.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Next.js. Для этого окружения сервер запускается на порту 4317.
